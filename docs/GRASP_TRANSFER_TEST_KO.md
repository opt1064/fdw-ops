# 시험 블록 수평 이송·목표 받침대 배치

기존 제자리 접촉·파지·유지·해제 시험이 Isaac Sim에서 6/6 통과한 다음 단계다. 이번 시험은 50 g 블록을 잡아 올리고 약 10~15 cm 수평 호 경로로 옮긴 뒤, 별도 받침대에 내려놓고 빈 그리퍼를 복귀시킨다. 실제 성공 여부는 새 실행의 로그와 화면으로 확인한다.

## 실행과 화면 확인

기존 시험 창을 닫은 뒤 실행한다. 타임라인 Play를 누르지 않는다.

```bash
cd ~/isaac_workspace/projects/fdw-ops-review
git status -sb
git pull --ff-only origin fix/fdw-quality-disposition-base-pose
bash scripts/run_gripper_transfer_review.sh
```

처음에는 기존 무부하 개폐 2회가 진행된다. 이후 **파란 출발 받침대**, **보라색 목표 받침대**, **노란 시험 블록**이 나타난다. 자동 카메라는 그리퍼와 두 받침대가 함께 보이도록 조정한다. 왼쪽 손가락 끝은 파란색, 오른쪽은 주황색, TCP 후보는 청록색으로 표시한다. 블록은 운반 중 녹색, 개방 중 주황색, 해제 후 복귀 중 하늘색, 실패 시 빨간색으로 바뀐다. 색상은 단계 표시이며 통과 판정 자체는 물리 피드백을 사용한다.

11단계 순서는 다음과 같다.

1. `SETTLE_ON_SUPPORT`: 출발 받침대 안착, 양쪽 손가락 접촉 없음.
2. `CLOSE_CONTACT`: 양쪽 손가락 접촉 후 1초 동안 파지와 팔이 안정되는지 확인.
3. `LIFT`: J5 최대 2도, 6초 동안 들어 올림.
4. `HOLD_UNSUPPORTED`: 받침대 접촉 없이 양쪽 손가락으로 3초 유지.
5. `TRANSFER`: J1 최대 8도, 6초 동안 목표 받침대 위로 이동. 기본 모델의 계산 거리는 약 124.5 mm이며 실제 시작 관절 좌표로 다시 계산한다.
6. `HOLD_AT_TARGET`: 목표 위에서 1초 유지.
7. `LOWER_TO_TARGET`: J5를 시작 각도로 되돌리며 목표 받침대에 내려놓고, 목표 접촉을 확인.
8. `OPEN_RELEASE`: 손가락을 열고 목표 받침대에 물체가 남는지 확인.
9. `RETREAT_EMPTY`: 열린 그리퍼만 위로 물러남.
10. `RETURN_ABOVE_SOURCE`: 그리퍼가 들린 높이에서 출발 쪽으로 돌아옴.
11. `RETURN_EMPTY`: 팔을 시작 관절 자세로 복귀. 물체는 목표 받침대에 남아 있어야 함.

최종 성공 표시는 **`PASSED_SIMULATED_GRASP_TRANSFER_PLACE`**, `grasp_test.passed_phases: 11`, `transfer_verified: true`, `target_placement_verified: true`다. JSON은 기존 `fdw_sim/logs/gripper_motion_*.json`에 저장한다. 출력 중 `grasp_test.phases`의 이송 실측 거리, 목표 수평 오차, 내려놓은 높이 차이, 받침대별 접촉력, 복귀 중 물체 좌표를 확인한다.

## 판정과 범위

- 두 받침대는 실제 블록과 받침대 크기를 반영하여 분리 배치한다. 목표 받침대가 처음부터 블록 아래에 있거나, 관절 제한을 지키는 10~15 cm 경로를 만들 수 없거나, 높이 여유를 확보할 수 없으면 시작하지 않는다. 41개 기구학 경로 표본에서 물체 바닥이 두 받침대 윗면보다 최소 8 mm 높아야 한다. 이는 전체 로봇의 연속 충돌 검증을 뜻하지 않는다.
- 수평 이송 중 양쪽 접촉을 유지하고, 양 받침대 접촉력은 0.01 N 미만, 실제 바닥 높이 여유는 최소 5 mm여야 한다. 그리퍼 기준 물체 위치 변화 3 mm, 자세 변화 5도 초과 또는 양쪽 접촉 상실이 0.1초를 넘으면 중단한다.
- 이송 완료 시 물체의 **실측 수평 이동이 최소 100 mm**, 목표 중심 수평 오차가 **3 mm 이내**여야 한다. 팔만 움직이고 블록이 남아 있으면 통과하지 않는다.
- 내려놓기는 목표 받침대 접촉, 출발 받침대 접촉 없음, 목표 높이 오차 2 mm 이내 및 자세 오차 5도 이내로 확인한다. 개방 뒤 양쪽 손가락 접촉이 사라져야 하며, 이후 세 단계의 빈 그리퍼 복귀 동안에도 목표 안착·위치·낮은 물체 속도를 매 스텝 확인한다. 출발 받침대 접촉으로 대신 통과할 수 없다.
- J1의 확대 범위는 명시적인 `--transfer-test`에만 적용한다. 기존 소폭 팔 시험의 최대 2도 범위는 유지한다. 새 시험은 J1 8도, J5 2도 이내 명령, 실제 위치는 각 명령 범위에 0.5도 여유를 더한 범위와 작성된 USD 관절 제한으로 감시한다. 다른 관절을 임의로 풀지 않는다.
- 기존 50 g 합성 블록·0.8 마찰계수·블록에만 0.4905 N 아래 방향 힘을 가하는 조건을 유지한다. 블록을 그리퍼에 연결하거나 시험 중 블록 좌표를 변경하지 않는다. 목표 받침대는 시험 시작 전에 만든 독립 정적 충돌체다.
- 실제 관절 기반 USD FK와 TCP 후보 좌표, 장착부 상대 좌표 검사를 계속한다. 원본 자산·로봇 물성·생산 파지 어댑터 설정은 바꾸지 않는다. 실기 로봇, 전체 중력, 생산 부품, 정격 하중, TCP 실측 보정의 검증은 별도다.
- 실패하면 물리 진행을 멈춘다. 물체를 자동으로 열어 떨어뜨리거나 옮겨 놓지 않는다. 로컬 CPU 테스트와 계산 경로 점검은 실제 Isaac 물리 이송 성공의 증거가 아니다.

기존 제자리 파지 시험은 [CONTACT_GRASP_TEST_KO.md](CONTACT_GRASP_TEST_KO.md)의 명령으로 계속 실행할 수 있다.

## 자동 종료와 실패 기록

리뷰 실행 스크립트는 동일 그리퍼 시험이 이미 실행 중이면 중복 시작을 차단한다. 표준 출력·오류를 `fdw_sim/logs/gripper_transfer_console_*.log`에 함께 기록하며, 종료 시 `SIM_EXIT_CODE`를 남긴다. 성공은 0, 검증 실패는 2이다. 창이 계속 열려 있는 동안에는 실행 스크립트도 대기한다.

시뮬레이터 시작 전에 고유 실행 ID를 만든다. 같은 ID의 `.json`은 최종 결과, `.events.jsonl`은 즉시 저장하는 단계 시작·완료·0.5초 간격 측정 기록이다. `.traceback.txt`는 Python 예외가 발생한 경우 생성한다. 부분 이벤트의 `IN_PROGRESS`는 성공 표시가 아니다. 강제 프로세스 종료나 네이티브 충돌로 최종 JSON이 없더라도 마지막 저장된 단계와 측정값을 확인할 수 있다. 이 경우 콘솔 로그와 `.events.jsonl`을 함께 확보한다.

NumPy 목표값으로 제어한 직후 실패하면 마지막 제어 기록에 NumPy 불리언이 남아 최종 JSON 저장까지 실패하던 문제를 수정했다. 원래 파지 오류를 직렬화 오류가 가리지 않도록 제어 기록을 기본 Python 형식으로 남기며, 예상하지 못한 직렬화 오류에도 원래 오류를 포함한 불완전 실패 JSON을 별도로 보존한다. 처리하지 못한 예외는 `app.close()` 전에 출력·저장하고, Isaac Sim 6.1의 `close(exit_code=...)`로 실패 종료 코드를 유지한다. API 근거: [NVIDIA SimulationApp 공개 API](https://docs.isaacsim.omniverse.nvidia.com/6.1.0/py/source/extensions/isaacsim.simulation_app/config/python_api.html).

이 수정은 실패 정보가 사라지는 경로를 재현·보완한 것이다. 2026-10-16 업로드 로그에 기록되지 않은 실제 `LIFT` 물리 중단 사유는 새 실행의 오류·측정값으로 확인해야 하며, 수평 이송 통과를 의미하지 않는다.

### 2026-10-16 추가 로그의 미끄러짐과 보완

`gripper_motion_20261016_102326_9e427815.json`에서는 제자리 안착·닫힘까지 통과했으나, LIFT 중 그리퍼 기준 물체 이동이 3.080 mm로 3 mm 한도를 넘었다. 해당 시점 양쪽 접촉력은 약 2.84/2.85 N이고 접촉은 유지되었다. 상대 자세 변화는 약 2.84도로 5도 이내였으므로 기록상 직접 실패 기준은 위치 미끄러짐이다. 닫힘 완료 시 팔 속도는 약 0.967도/초로, 파지가 안정되기 전에 들어 올리던 순서를 보완했다.

닫힘 단계는 최대 12초 안에 양쪽 접촉력 각각 1 N 이상, 팔 속도 0.2도/초 이하, 그리퍼 속도 0.5도/초 이하, 팔 목표 오차 0.1도 이하, 물체 속도 2 mm/초 이하를 1초 유지해야 한다. 그 시간 동안 그리퍼 기준 물체 위치·자세 변화는 0.5 mm/0.5도 이내, 접촉력 변화는 20% 이내여야 한다. 물체 좌표와 접촉력을 보정하거나 강제로 고정하지 않는다. 이후 LIFT를 6초 동안 진행한다. 3 mm/5도 미끄러짐 한도와 기존 로봇 힘 제한은 그대로다.

목표 받침대의 폭 방향 길이는 최대 20 mm로 줄였다. 새 받침대 생성 후, 실제 로봇과 그리퍼의 모든 활성 충돌 형상 경계를 재어 목표 받침대와 최소 3 mm 간격이 있는지 검사한다. 숨겨진 충돌 형상과 인스턴스 프록시도 포함하며 빈 경계나 측정 실패는 진행을 차단한다. 이는 초기 자세의 보수적 AABB 검사이며 전체 이송 경로의 충돌 검증은 아니다. 이전 로그만으로 목표 받침대 간섭을 확정한 것은 아니며, 새 로그에 가장 가까운 충돌 형상과 간격을 남긴다. 실제 이송 통과는 재실행으로 확인해야 한다.
